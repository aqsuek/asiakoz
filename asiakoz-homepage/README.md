# ASIAKÖZ Homepage (React + Tailwind)

Премиальная главная страница глазной клиники ASIAKÖZ по дизайн-референсу.

## Запуск

```bash
cd asiakoz-homepage
npm install
npm run dev
```

Откройте http://localhost:5173

## Сборка

```bash
npm run build
npm run preview
```

## Стек

- React 18
- Vite 6
- Tailwind CSS 3
- Lucide React (иконки)

## Секции

Header, Hero, Trust stats, Services, Doctors, Why choose, Process, Reviews, Footer, Fixed WhatsApp CTA.

Акцентный цвет: `#12B7D5`.
